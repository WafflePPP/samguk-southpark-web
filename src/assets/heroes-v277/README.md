# 장수 8방향 보행 이미지

- 기존 장수 27개 기본 외형을 내장 image_gen으로 8방향 × 4보행 프레임씩 확장. 현재 장수 114명은 기존과 같은 외형 공유 관계를 유지한다. 일반 병사 이미지는 변경하지 않는다.
- 방향 행 순서: 동(E), 남동(SE), 남(S), 남서(SW), 서(W), 북서(NW), 북(N), 북동(NE). 게임 좌표는 오른쪽이 +X, 아래쪽이 +Y다.
- 각 PNG는 한 외형의 원본이다. 기본 배치는 4열(보행) × 8행(방향), `grid.json`에 columns로 기록된 외형은 8열(방향) × 4행(보행)이다. 실제 방향 그림을 사용하며 런타임 좌우 반전을 하지 않는다.
- `layout.json`은 `node tools/hero-atlas.js`로 생성한 연결 알파 경계. 원본 PNG는 보존하며, 런타임에 해당 캐릭터의 연결 알파만 추출해 반투명 배경과 이웃 이미지를 제거한다.
- 장수마다 최대 프레임 높이로 배율을 고정하고 발 기준점을 정렬해 보행 중 몸 크기가 변하는 현상을 줄인다. 초당 8프레임 재생, 장수별 보행 시작 위상 분산. 정지 시 해당 방향의 첫 프레임.
- 찌르기·베기·시전·피격 등 기존 행동 타이머/변형/도트 궤적은 새 방향 이미지에 함께 적용한다. 이 시트는 보행 자세이며 별도 공격 전용 그림은 아니다.
- `prompts.json`에 외형별 원본 생성 프롬프트를 기록. 사용자 제공 이미지는 방향별 보행 구성 참고용이며 직접 복제한 에셋이 아니다.
- 검증: `node test/hero-directions.test.js`, `node test/pixel-art.test.js`, `node test/battle-assets.test.js`.
