# 여포 기준 장수 15종 리워크

- 대상: 원소·안량·문추·고순·조조·하후돈·하후연·전위·허저·곽가·사마의·유비·관우·제갈량·조운.
- 기존 장수 이미지는 무기·복식·정체성 참고, 여포 `lubu-v284`는 작은 비율·도트 윤곽·단순 음영 기준. 내장 image_gen으로 최종 애니메이션 시트를 직접 제작했다. 원본 생성/수정 프롬프트는 `prompts.json`.
- 각 PNG는 8열×9행의 72컷: 첫 행 대기8, 다음4행 보행32, 마지막4행 동작1/회수1/동작2/회수2. 열은 동·남동·남·남서·서·북서·북·북동. 근접은 찌르기/베기, 하후연은 사격/근접, 군사3명은 시전/보조 동작이다. 보조 동작 그림은 기술을 새로 부여하지 않는다.
- `node tools/hero-rework-atlas.js`로 실제72개 연결 영역과 행/열 순서를 검증해 `layout.json`을 기록한다. 원본 PNG는 편집하지 않고 런타임에서 알파200 연결 영역을 추출한다.
- 기존 대기/동작 전환·발 기준·몸체 높이 보정·호흡·효과를 재사용한다. 전투와 로비·전략·편성·상세 모두 같은 모델을 사용한다. 요청하지 않은 장수와 병사는 기존 외형 유지. 능력치·병종·기술·전투 규칙 변경 없음.
- 로더는 교체 대상의 옛 보행·대기 PNG 추출을 건너뛰어 중복 캔버스/이미지 메모리 사용을 줄인다. 누락·잘못된 시트는 로드 실패로 처리해 투명한 장수로 전투가 진행되지 않도록 한다.
- 추출 캔버스는 `willReadFrequently`로 픽셀 읽기에 맞춰 생성한다. 브라우저에서 전투·상세·창 크기 전환 후에도 실제 불투명 픽셀이 남는지 확인했다.
