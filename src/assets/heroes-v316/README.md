# 여령기 기준 여포·고순 v0.1.316

여령기 `rework-v303/lulingqi.png`를 화풍·머리/몸·기수/말 비율의 단일 기준으로 사용한다. 기존 여포·고순 시트는 무장과 색상 참고로만 사용했다.

- 투명 PNG, 8열 × 8행, 64컷
- 대기 1행, 보행 3행, 찌르기 타격/회수 2행, 베기 타격/회수 2행
- 방향: 동·남동·남·남서·서·북서·북·북동
- 내장 ImageGen 사용. 인물·무기·말은 프레임마다 하나의 연결 영역이다.

검증: `node tools/hero-rework-atlas.js --root=src/assets/heroes-v316`
