# 전투 아트 — 승인 시안 기반 이미지 에셋

- 기준: `approved-reference.png` (승인된 여포 기병·창병·평야 시안 원본).
- 제작: 내장 `image_gen` 사용. 프롬프트 전문·시트별 순서는 `prompts.json`, `back-prompts.json`, `shield-edit-prompt.txt`.
- `units-0.png`~`units-3.png`(앞), `back-0.png`~`back-3.png`(뒤): 각12종 × 2프레임, 총48종·192프레임. 고유 장수/병종46스타일 + 일반 아군/적군 창병2종. 좌우 반전으로 4방향 표현.
- 시트의 실제 스프라이트 연결 영역을 `tools/battle-atlas.js`로 읽어 `layout.json`에 기록. 이미지 픽셀 파일은 수정하지 않음. 생성물이 정해진 칸을 일부 넘기므로 균등 칸 자르기는 사용하지 않음.
- `terrain.png`·`terrain-layout.json`: 지형 텍스처와 수풀/바위의 투명 경계. 잔디는 승인 원본의 빈 잔디 구역(490,25,256,256)을 샘플링.
- 런타임은 연결된 알파 영역만 추출해 이웃 무기가 섞이지 않게 하고, 적 고유 병종의 청색 천을 암적으로 바꿔 팀 구분을 유지. 기울임·좌우 반전·보행 프레임·피격 반짝임은 이미지 렌더에서 처리.
- 타이틀·전략 화면은 이 PNG를 사용하지 않음. 이미지 로드 전에는 전투 시뮬레이션을 정지하고, 실패 시 재시도 안내를 표시.
- 검증: `node test/battle-assets.test.js` / `node test/pixel-art.test.js`.

새 캐릭터·포즈는 승인된 두 캐릭터를 기준으로 확장 제작한 이미지이며, 승인 원본 그림 전체를 그대로 배경으로 붙인 방식은 아님.
