# 여포 기준 초선 외형 통일

- 여포 `lubu-v284`를 도트 윤곽·단순 음영·얼굴 표현 기준으로 새 초선 최종 시트 제작. 기존 초선은 의상·긴 머리·꽃관·부채의 정체성만 참고했다. 내장 image_gen 사용, 생성 프롬프트는 `prompts.json`.
- 기존 짧은 몸통을 늘리고 분홍색/크림색 옷·금색 가장자리·부채를 유지. 여포는 기준 외형을 보존하고 장료 표시 높이는 4.8r→4.4r, 초선은 3.6r→4.7r로 조정. 전투 반경·능력치·기술은 변경하지 않는다.
- `idle.png`:8열×1행 대기, `walk.png`:8열×4행 보행. 열은 동·남동·남·남서·서·북서·북·북동. `node tools/lubu-atlas.js src/assets/diao-v289 --idle-walk`로 실제40컷을 검증한다.
- 원본 PNG를 보존하며 알파200 연결 영역 추출·발 정렬·프레임별 몸체 높이 보정·호흡·기존 시전/치유 동작을 재사용한다. 전용 창/칼 공격 시트는 연결하지 않는다.
- 전투·초상·전략 상세에서 새 초선 외형을 사용한다. 다른 장수·병사 외형은 변경하지 않는다.
