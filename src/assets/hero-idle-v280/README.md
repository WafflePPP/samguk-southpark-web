# 장수 대기 기준 자세

- 내장 image_gen으로 기존 장수27개 기본 외형의 8방향 전용 대기 자세216장을 제작. 보행 첫 프레임과 별도 이미지이며 보병 양발·말의 네 발을 땅에 둔 기본 준비 자세다.
- 각 시트: 8열(동·남동·남·남서·서·북서·북·북동) × 3행(장수). `groups.json`은 행별 장수, `layout.json`은 실제 연결 알파 경계. 원본 생성 프롬프트는 `prompts.json`.
- `node tools/idle-atlas.js`로 24개 독립 연결 영역과 격자 순서를 검증한다. 원본 PNG는 보존하고 런타임에 해당 캐릭터의 알파만 추출한다.
- 대기 때 발 기준점을 고정한 미세 호흡, 상태·방향 전환 때 지수 보간. 전환 중 상태가 바뀌어도 최대4개 자세만 남기고 가중치 합을1로 유지한다. 몸 이동·기울임·호흡은 가중치로 보간하고, 이미지는 가장 큰 가중치의 자세 한 장만 그려 반투명 잔상과 이중 윤곽을 방지한다.
- 시계는 전투 `S.t`를 사용해 일시정지·대화 중 보행/호흡/전환도 정지한다. 전투 유닛 자체를 수정하지 않는 WeakMap 렌더 캐시이며 전투 객체가 해제되면 함께 회수된다.
- 찌르기·베기·사격·시전은 대기 기준점에서 출발해 정점을 거쳐 돌아오는 시각 곡선. 기존 공격 판정·피해·상태 타이머는 바꾸지 않는다.

무기·장식의 희박한 상단(알파 질량15%)을 제외한 몸체 높이를 비교해 대기/보행의 배율을 맞춘다. 대기 알파 추출 기준200은 경계 검증 도구와 동일하다.
