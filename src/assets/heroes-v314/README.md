# 여포 기준 장수 외형 v0.1.314

첨부 전투 화면에 등장하는 장수 6종을 실제 여포 시트의 비율과 픽셀 문법으로 다시 제작한다.

- 비율: 큰 머리, 짧고 굵은 몸과 팔다리, 기병은 여포의 말·기수 비율
- 표현: 1논리 픽셀 검정 외곽선, 3~4픽셀 사각 덩어리, 16색 이하, 2단 명암
- 형식: 투명 PNG, 8열 × 7행, 대기·보행 2행·동작 2종 각 타격/회수
- 방향: 동·남동·남·남서·서·북서·북·북동
- 제외: 광택 그라데이션, 부드러운 반투명 가장자리, 그림자, 효과, 격자, 문자

`node tools/hero-rework-atlas.js --root=src/assets/heroes-v314`로 연결 영역 56개와 배열을 검증한다.
