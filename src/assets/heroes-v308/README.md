# 장수 외형 v0.1.308

여포 리워크와 같은 기준으로, 기존에 이질감이 남은 장수 공유 외형 25종을 교체한다. 여포·장료·여령기·화웅형은 기존 시트를 유지한다.

- 형식: 투명 배경 PNG, 8열 × 7행, 총 56컷
- 행: 대기 1행, 보행 2행, 제1동작 타격/회수 2행, 제2동작 타격/회수 2행
- 방향: 좌상·좌·좌하·하·우하·우·우상·상
- 공통 제작 프롬프트: `여포 리워크와 같은 성인형 SD 도트 스프라이트. 작은 머리, 긴 팔다리, 조밀하고 각진 픽셀, 절제된 명암, 선명한 실루엣. 프레임마다 인물과 장비는 한 덩어리로 연결하고 잘림·문자·격자선·그림자는 제외한다.`
- 캐릭터별 무장·색·동작은 `prompts.json`에 기록한다.

`node tools/hero-rework-atlas.js --root=src/assets/heroes-v308`로 투명 연결 영역 56개와 배열 순서를 검증하고 `layout.json`을 생성한다.
