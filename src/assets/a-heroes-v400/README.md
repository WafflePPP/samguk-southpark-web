# A등급 고유 장수 v0.1.400 — 유비 세력 전면 재작

- 기존 시트는 인물의 관모·복장·무기·말·대표색만 참조하고 스프라이트는 빈 캔버스에서 새로 그렸다.
- 화풍 기준은 `lubu-faction-v387`의 직업별 시트다: 굵은 하드엣지 픽셀 외곽선, 큰 머리와 장화, 3~5단 평면 명암.
- 대상: 유비·관우·장비·조운·제갈량·황충·마초.
- 각 PNG는 8열×7행 56컷이다: 대기 8, 보행 16, 공격 32. 제갈량은 시전/회복, 황충은 사격/근접, 나머지는 찌르기/베기다.
- 런타임 전용 그림 키는 `a_`+장수키다. 병종·판정·능력치는 바꾸지 않는다.
- 검증: `node tools/lubu-faction-atlas.js src/assets/a-heroes-v400`.
