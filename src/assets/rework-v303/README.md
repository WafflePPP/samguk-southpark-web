# 남은 장수·병사 전체 리워크 (v0.1.303)

내장 imagegen으로 여포(`lubu-v284/idle.png`)의 픽셀·머리/몸통·기수/말 비율을 참고하여 최종 시트를 직접 제작했다. 중간 원화 제작 단계 없음. 기존 리워크 완료18장수계열/병사6종을 유지하고 남은20종을 교체한다.

총 원본1224컷(64컷13종·56컷7종), 공유 포함118개 유닛 항목에 적용. 전체 적용 목록은 `usage.json`, 최초 제작 프롬프트는 `prompts.json`, 채택 원본·편집 내역은 `generation.json`. 생성20회·오류 보완13회.

각 시트는 8방향 열(E/SE/S/SW/W/NW/N/NE), 대기8·보행16또는24·동작/회수32다. 보행2자세는0→1→0→1, 3자세는0→1→2→1로 재생한다. 사격/시전 모델도 해당 동작/회수를 사용한다. 1224개 고유 프레임과 반복 재생 슬롯 수는 다르다. 일부 인접 방향/회수 자세는 유사하고 정면 무기가 몸 뒤에 가려지는 구도가 있다.

원본 PNG 알파는 보존한다. 게임은 연결된 알파 영역만 추출하고 최근접 픽셀 축소(높이128px 상한), 적군 색상 처리를 한다. 일반 법사/회복병은 같은 로브·부채 외형을 공유한다. 화웅·황충·순욱·공유 기마형은 기존 연결된 장수 전체가 새 외형을 공유하며 각 인물별 유니크 외형을 추가한 것은 아니다.

시각 배율은 여포 기준 v302를 유지한다. 병과·수치·격자·판정·저장 변경 없음. 기존 캐릭터의 오래된 앞뒤/방향 PNG는 보존하지만 더 이상 로드/추출하지 않는다.

검사: `node tools/hero-rework-atlas.js --root=src/assets/rework-v303`, `node test/remaining-rework.test.js`. 실제 PNG 투명 연결 영역·프레임 경계·모든148유닛/47기본외형 매핑·8방향 대기/보행/동작/회수·아군/적·UI를 검사한다.
