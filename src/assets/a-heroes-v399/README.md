# A등급 고유 장수 v0.1.399 — 유비 세력

- 내장 imagegen으로 기존 고유 시트의 얼굴·복장·무기·말·대표색을 유지하고 `lubu-v390`의 큰 머리·굵은 픽셀 외곽선·3~5단 명암에 맞춰 다시 그렸다.
- 대상: 유비·관우·장비·조운·제갈량·황충·마초.
- 각 PNG는 8열×7행 56컷이다: 대기 8, 보행 16, 공격 32. 제갈량은 시전/회복, 황충은 사격/근접, 나머지는 찌르기/베기다.
- 런타임 전용 그림 키는 `a_`+장수키다. 병종·판정·능력치는 바꾸지 않는다.
- 검증: `node tools/lubu-faction-atlas.js src/assets/a-heroes-v399`.
