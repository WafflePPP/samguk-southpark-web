# 장료 전용 최종 도트

- 사용자 제공 원화는 복식·인물 참고, `lubu-v284`는 작은 비율·도트 표현 기준. 별도 중간 시안 없이 내장 image_gen으로 최종 게임용 시트 3장 제작.
- 은색 투구·동색 장식·한 줄기 청보라 깃, 짧은 검은 수염, 보라색 목도리와 망토, 검은 철갑과 검은 말. 기존 창 기병 설정을 유지하며 단일 은색 창날·붉은 술을 사용한다.
- `idle.png`: 8열×1행. `walk.png`: 8열×4행 보행. `attack.png`: 8열×4행 찌르기·회수·휘두르기·회수. 모든 열 방향은 동·남동·남·남서·서·북서·북·북동.
- `node tools/lubu-atlas.js src/assets/zhangliao-v287`로 72컷 경계를 기록. 원본 PNG를 보존하고 기존 런타임의 알파200 연결 영역 추출을 재사용한다.
- 장료의 style만 `zhangliao`로 분리. 한거자·조휴 및 다른 기존 `jang` 공유 장수들은 기존 이미지를 유지한다. 전투·초상·전략 상세에 같은 새 모델 사용, 능력치·기술·전투 규칙 변경 없음.
