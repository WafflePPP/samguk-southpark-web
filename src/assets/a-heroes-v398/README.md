# A등급 고유 장수 v0.1.398 — 조조 세력

- 내장 imagegen으로 기존 고유 시트의 얼굴·복장·무기·말·대표색을 유지하고 `lubu-v390`의 큰 머리·굵은 픽셀 외곽선·3~5단 명암에 맞춰 다시 그렸다.
- 대상: 조조·하후돈·전위·하후연·곽가·순욱·사마의·허저·서황.
- 각 PNG는 8열×7행 56컷이다: 대기 8, 보행 16, 공격 32. 하후연은 사격/근접, 책사 3명은 시전/회복, 나머지는 찌르기/베기다.
- 런타임 전용 그림 키는 `a_`+장수키다. 병종·판정·능력치는 바꾸지 않는다.
- 검증: `node tools/lubu-faction-atlas.js src/assets/a-heroes-v398`.
