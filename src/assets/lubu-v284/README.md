# 여포 전용 리워크

- 사용자 제공 방천화극 사진의 중앙 창날+양쪽 월아날, 여포 복식 사진의 검은 철갑·붉은 머리띠·상아색 쌍깃을 반영. 퍼스트퀸4 캐릭터 시트는 작은 도트 비율·윤곽·음영 참고이며 캐릭터를 그대로 복제한 에셋은 아니다.
- 기존 기마 설정 유지. 적갈색 말·검은 갈기·붉은 마구, 흰 허리 천과 절제된 금속 견갑으로 식별한다. 내장 image_gen 제작, 최종 프롬프트는 `prompts.json`.
- `idle.png`: 8열×1행, 대기8방향. `walk.png`: 8열×4행, 보행4단계. `attack.png`: 8열×4행, 찌르기/찌르기 회수/베기/베기 회수.
- 열 방향: 동·남동·남·남서·서·북서·북·북동. `node tools/lubu-atlas.js`로 실제 연결 알파 경계와 72칸을 검증한다. 런타임 추출 기준은 알파200.
- 기존 장수 로드 뒤 `lubu` 모델의 대기·보행·공격만 교체한다. 몸체 알파 질량으로 배율을 맞추고 기존 대기/동작 전환·발 기준점·피격·전사 연출을 유지한다. 여포의 타이틀·전략 상세·전투 초상도 같은 디자인 사용.
- 다른 장수/병사의 PNG와 모델, 전투 판정·수치·저장 형식은 바꾸지 않는다.
