# 여포 비기마 창병 교체 (v0.1.380)

- `lubu.png`: 1024×1536 투명 PNG, 8열×8행 64컷.
- 방향 순서: 동·남동·남·남서·서·북서·북·북동.
- 행 구성: 대기, 보행 3행, 창 찌르기 2행, 창 횡베기 2행.
- 첨부 작은 이미지를 캐릭터 외형·비기마 체형·큰 장화·굵은 도트 화풍의 최우선 참고로 사용했다.
- 주황빛 머리·붉은 목도리·회색 상의·파란 허리천·밝은 발목 보호대·큰 갈색 장화를 최대한 유지하고 무기만 장창으로 변경했다.
- 기존 `lubu-v378`의 여포 시그니처는 사용하지 않고 자산 전체를 삭제한다.
- `heroes-v318/gao.png`는 비기마 64컷 배치·방향·동작 규격 참고로만 사용했다.
- OpenAI 내장 ImageGen으로 제작하고 `tools/hero-rework-atlas.js`로 64개 연결 영역을 검증했다.
