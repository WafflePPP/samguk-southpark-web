# 여포 승인 시안 재구현 (v0.1.381)

- 승인된 정면 시안의 주황빛 머리·붉은 목도리·회색 민소매 상의·파란 허리천·큰 갈색 장화와 단순 장창을 외형 기준으로 고정했다.
- `idle.png` 8컷, `walk.png` 32컷, `attack.png` 32컷으로 나눠 단일 64컷 일괄 생성에서 발생한 얼굴·비율·동작 흔들림을 줄였다.
- 방향은 동·남동·남·남서·서·북서·북·북동. 공격은 찌르기·회수·창 횡베기·회수 순서다.
- 알파 200 기준 실제 연결 영역 72개를 `node tools/lubu-atlas.js src/assets/lubu-v381`로 검증한다. 런타임 추출 과정에서 낮은 알파의 생성 배경은 제거된다.
- 다른 장수·병사 외형과 전투 분류·돌진·피해·수치는 변경하지 않는다.
